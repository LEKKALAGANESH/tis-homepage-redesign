## Source of truth

The primary requirements source is the supplied **TIS Homepage Redesign — Technical Reference Guide**. It defines the objective, recommended technology choices, component strategy, four standout feature options, evaluation weights, and submission checklist.

This documentation deliberately distinguishes:
- **Required by the assessment**
- **Recommended by the assessment**
- **Engineering decisions made for this project**
- **Items that must be verified against the implementation before being claimed**

No document in this folder should be treated as proof that a feature exists in code unless the implementation has been verified.

## Project principle

The redesign should feel modern and premium without sacrificing:
- semantic structure,
- accessibility,
- responsive behavior,
- animation performance,
- maintainability,
- and clarity of conversion-focused calls to action.
