# UX / UI Design Specification

## 1. Design objective

Create a premium school homepage that feels modern and intentional while preserving TIS's existing brand identity and core copy.

The assessment explicitly asks for:
- high-converting hierarchy;
- clear CTAs;
- modern typography;
- premium school aesthetic;
- strong visual polish.

## 2. Information architecture

Recommended homepage flow:

1. Global navigation
2. Hero / primary value proposition
3. About / school positioning
4. Academic or program information
5. Supporting proof / testimonials
6. Conversion CTA
7. Footer

The exact final section inventory should follow the source website/content and actual implementation.

## 3. Visual hierarchy

The visual hierarchy should answer, in order:

### Level 1 — Where am I?
Brand and school identity.

### Level 2 — Why should I care?
Primary value proposition.

### Level 3 — What do you offer?
Programs, academics, facilities, or relevant information.

### Level 4 — Why should I trust you?
Proof, statistics, testimonials, or supporting evidence where supplied.

### Level 5 — What should I do next?
Primary CTA.

## 4. Typography

Typography should create clear differentiation between:
- display headings;
- section headings;
- supporting copy;
- labels;
- CTA text.

Avoid using size alone to communicate hierarchy. Weight, line-height, spacing, and placement should work together.

## 5. Spacing

Use a consistent spacing system rather than arbitrary section-specific values.

A practical rule:
- tight spacing for related elements;
- medium spacing between content groups;
- large spacing between major sections.

## 6. Cards and surfaces

Cards should be used when grouping information provides a meaningful interaction or reading benefit.

Avoid turning every piece of content into a card. Excessive containers reduce hierarchy.

## 7. CTA design

The primary CTA should:
- have clear text;
- have sufficient contrast;
- have an obvious interactive state;
- remain accessible on touch devices;
- not compete with every secondary action.

## 8. Responsive behavior

### Mobile
Prioritize:
- readable typography;
- simple navigation;
- vertical content flow;
- touch-friendly controls;
- reduced visual complexity where needed.

### Tablet
Use available width for structured two-column or grid layouts where content remains readable.

### Desktop
Use whitespace, larger visual composition, and multi-column structures without allowing content width to become excessive.

## 9. Interaction states

Every interactive component should be considered across:
- default;
- hover;
- focus;
- active;
- disabled;
- loading/error states where applicable.

## 10. Design principle

The design should communicate quality through consistency rather than decoration. Motion, gradients, shadows, imagery, and special effects should reinforce the school's narrative instead of becoming the narrative.
